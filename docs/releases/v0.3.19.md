# 河豚运营中心 v0.3.19

本版补齐页面编排中已绑定轮播的外观编辑。选择一级分类页面后，可直接调整该页轮播，修改自动保存，当前 Vue 页面按保存的参数显示。

## 本版更新

- 新增通栏、内嵌、两侧露出、海报、分栏五种轮播样式。
- 支持宽度 40%–100%、高度 120–600px、边距 0–48px、圆角 0–300px，以及图片覆盖或完整显示。
- 各一级分类页面独立保存轮播外观；切换分类不会共用本页设置，轮播组内容及分类绑定仍由轮播图中心维护。
- 支持恢复主题默认。未设置或已重置的字段继续继承主题，兼容旧页面配置。
- 修复轮播外观只显示已绑定、无法调整，以及参数未保存或未参与渲染的问题；服务端增加字段白名单和参数范围校验，非法请求不会覆盖原有配置。
- 新增轮播外观回归并接入正式 CI，统一软件、前端 manifest 和 Go 程序版本为 0.3.19。

## 安装与升级

提供 Linux amd64、Linux arm64、Windows amd64 单程序压缩包及 SHA256SUMS.txt。普通宝塔 x86 服务器选择 linux-amd64，ARM64 服务器选择 linux-arm64。

已有 Linux 安装可在「系统管理 → 系统更新」检查本版。手动升级前备份数据库、config.json 和完整 data 目录，停止服务后仅替换对应平台的可执行文件，再重新启动。

## 接入范围

本版交付运营中心编辑界面、后端保存接口及现有 Vue 轮播组件对外观参数的呈现。主题中心、打包器及原生客户端没有在本次改动中更新；原生设备接入与生产部署需分别验收。
