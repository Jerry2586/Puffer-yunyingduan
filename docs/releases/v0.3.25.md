# 河豚运营中心 v0.3.25

修复旧版苹果 CMS 的注册、订单读取与积分升级接口不兼容问题。注册先通过只读接口识别 CMS，再向对应入口提交一次；请求失败不会换接口重复注册。旧版注册使用 CMS 自身的注册校验和登录会话，避免成功后再次登录导致验证码错误。

订单列表与订单状态改由河豚适配器兼容旧版 CMS，每次重新验证登录，并按当前会员限定查询范围；只返回公开订单字段，限制分页和结果数量。旧版积分升级沿用 CMS 原生权限和余额校验。现金充值、支付及新式会员订单的旧版兼容不在本次变更中。

更新运营程序后，在“内容源与连接”执行“安装 / 更新到本地 CMS”。自动升级仅匹配已发布 v0.3.21、v0.3.22 / v0.3.23、v0.3.24 适配器的完整原始字节，保留管理密钥及文件权限，持久化失败时回滚；自定义文件仍报告冲突。

回归覆盖新旧注册入口选择、只提交一次、原生验证码错误、注册 Cookie 会话、订单归属与字段过滤，以及各代适配器升级和回滚。
