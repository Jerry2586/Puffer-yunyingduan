# 河豚运营中心 v0.3.26

播放中心统一管理播放源、解析器、播放内核和弹幕。支持读取同机苹果 CMS 静态播放器规则，也可使用管理适配器导入来源；读取不执行 PHP，不向客户端暴露 CMS 解析地址。

每条 CMS 播放源可以绑定已发布解析器并调整尝试顺序，支持自动、只用直链和指定解析。绑定不存在或重复的解析器会被拒绝；删除仍在使用的解析器时必须先解除绑定。解析失败沿配置继续尝试，客户端排除已失败直链后不会再次返回同一直链。

新增排期管理的添加、编辑和删除界面，沿用当前客户端的日期、分类和影片 ID 契约持久保存。系统总览的安装时长根据首次安装时间累计，跨天显示总天数，包含停机时间；缺少首次安装记录时明确提示。

安装时长回归已接入 CI 和正式发布流程。程序、前端清单和包版本统一为 0.3.26。正式成品为 Linux amd64、Linux arm64 和 Windows amd64 三种单文件安装归档，附 SHA256SUMS.txt。

本次发布运营服务及管理页面；媒体源自身的不可用、设备解码和投屏仍需在实际环境验收。已有样本上游视频分片返回 404，发布不代表该片源已恢复。服务器安装本版本后才会使用新增调度逻辑；原生 App 的发布与客户端接入另行交付。
