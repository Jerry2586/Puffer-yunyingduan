# 河豚运营中心 v0.3.16

本版将已完成的导航、分类、轮播图与排版调整打入正式安装包。后台编辑自动保存，并通过现有运营接口提供客户端可读配置。

## 本版更新

- 导航与分类绑定分别管理一级分类、中间导航、底部导航和左上角菜单；一级分类支持 CMS 目录及页面绑定。
- 中间导航按 APP 一级分类独立绑定、开启或关闭，支持文字与图文形式；全部、排期表和排行榜使用所属分类范围，底部对应功能仍使用全局范围。
- 轮播图中心支持创建模块、原地改名和绑定一级分类；一个一级分类对应一个轮播模块，轮播内容可在表格中编辑、排序、开启或隐藏。
- 页面编排中的轮播引用轮播图中心模块，减少重复配置。
- 栏目支持列数、数量、比例、宽度、间距、圆角、标题字号和颜色；左上角菜单与中间导航支持各自尺寸、排列、间距及文字颜色设置。
- 后台变更自动调用 apply 保存并更新客户端可读配置，保留版本冲突检测和失败提示。客户端按现有轮询策略读取，保存成功不代表设备已经接收。
- package.json、锁文件、前端 manifest、Go 默认版本及正式程序版本统一为 0.3.16，下载说明同步更新。

## 安装与升级

提供 Linux amd64、Linux arm64、Windows amd64 单程序压缩包及 SHA256SUMS.txt。常见宝塔 x86 服务器选择 linux-amd64，ARM64 服务器选择 linux-arm64。

已有 Linux 安装可在“系统管理 → 系统更新”检查本版。手动更新前备份数据库、config.json 和完整 data 目录，停止服务后仅替换对应平台的可执行文件，再重新启动。

## 接入范围

本版交付运营中心管理页面、后端接口和当前 Vue 页面对排版参数的呈现。主题中心、打包器及原生客户端对新增参数的接入待后续完成；本次发布没有修改这两个中心，也不代表已完成真机联调或生产部署。

既有 CMS、会员与播放权限、轮询解析及播放器策略接口继续保留；原生播放与第三方商业 SDK 的接入边界仍以既有接口文档为准。
