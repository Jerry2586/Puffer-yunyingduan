# 河豚运营中心 v0.3.22

修复部分旧版苹果 CMS 在调用播放接口时找不到 check_user_popedom() 的错误。播放适配器继承 CMS 的 Base 控制器，继续通过 CMS 原有权限检查读取播放地址；拒绝权限、密码保护、下架及非 HTTP 地址均不返回可播放 URL。

同机安装支持更新字节摘要与 v0.3.21 官方文件完全一致的旧播放适配器，保留管理密钥、文件权限和站点自行修改的文件。写入前核对全部目标，替换前复核文件身份与内容；持久化失败时恢复旧播放适配器并回滚本次新建文件。连接配置按钮标明安装 / 更新。

新增 PHP 权限与令牌行为回归，以及安装升级、冲突保护、回滚与幂等 Go 回归。线上程序更新后，需要在视频管理的连接配置中执行“安装 / 更新到本地 CMS”。文件安装和管理连接通过，仍须单独实际验证播放、会员与支付。
