# 河豚运营中心 v0.3.24

修复旧版苹果 CMS V10 缺少新版会员接口时，会员页显示 HTTP 404、登录后无法读取账号资料的问题。新版接口确实返回 HTTP 404 时，账号资料与套餐读取改用河豚适配器，登录改用 CMS 自身的旧版登录入口。错误密码、登录失效、服务器错误、跳转和非 JSON 响应均保留原错误。

适配器通过 CMS 的 checkLogin 重新验证会话，只返回允许公开的账号字段和已启用会员组，尊重会员到期后的实际分组。旧版站点仅提供积分套餐时，不生成现金会员价格。注册、订单与支付接口不因这次读取兼容而自动获得旧版支持。

更新运营程序后，请在“内容源与连接”中执行“安装 / 更新到本地 CMS”。自动更新仅接受本程序已发布的 v0.3.21、v0.3.22 / v0.3.23 适配器完整原始字节；自定义文件保持冲突保护。更新保留管理密钥和文件权限，配置持久化失败时回滚。

本地回归覆盖旧版子目录站点、登录 Cookie、会话隔离、敏感字段过滤、启用分组筛选、错误回退边界及两代适配器升级/回滚。真实支付与原生客户端仍须相应环境验收。
