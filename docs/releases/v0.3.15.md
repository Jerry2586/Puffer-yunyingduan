# 河豚运营中心 v0.3.15

本版新增运营端的轮询解析与播放器内核策略管理，沿用一个苹果 CMS 对接一个运营中心、四类客户端共用业务实现的架构。

## 本版更新

- 新增“轮询解析播放器”独立入口，位于电脑客户端下方、系统管理上方。
- 解析来源支持顺序、启停、客户端范围、JSON GET 与 HTTP 跳转，支持单来源超时、整体解析预算、最大尝试次数及排除已尝试来源。
- 支持解析草稿保存、单独发布及真实 HTTP 接口测试。播放请求继续先通过原有 CMS 与会员播放授权，所有来源失败会返回明确错误。
- 新增播放器内核管理：手机 Android/iOS、平板 Android/iPadOS、电视 Android、电脑 Windows/浏览器，共七个设备与系统策略。
- 支持登记基础包能力声明、配置主备内核与切换策略、草稿保存和发布、客户端能力协商，以及授权播放后签发的反馈凭据。
- 能力声明与客户端反馈分别呈现。未取得客户端反馈时显示“未检测”，不把候选 SDK 列表当作实际安装结果。
- 同步源码版本、前端 manifest 和 Go 默认版本为 0.3.15；正式二进制继续从 package.json 注入版本。

## 接入与升级

- 新旧安装默认关闭解析轮询和内核策略，保留现有播放行为。管理员应登记真实来源或基础包能力后，再保存和发布对应配置。
- 已有客户端可继续使用原播放接口。需要新内核能力的客户端按 docs/playback-engines-api.md 接入；解析续试按 docs/playback-resolvers-api.md 接入。
- 既有 Linux 安装可在“系统管理 → 系统更新”检查本版，确认后更新。手动替换前备份数据库、config.json 和完整 data 目录，仅替换对应平台程序。
- 提供 Linux amd64、Linux arm64、Windows amd64 单程序归档及 SHA256SUMS.txt。Windows 包用于本机运行及检查版本。

## 验证边界

本次交付运营端管理页面与后端接口。当前 Android 基础源码仍使用 VideoView，新策略协议的原生适配器、SDK 接入、自动或手动内核切换、跨请求播放预算、打包器能力清单导出及设备回调尚待客户端实现。

iOS/iPadOS/Windows 原生播放器、第三方商业 SDK 授权验证、真实外部解析供应商和真机完整播放尚未验收。后台能力登记与签名反馈不等同于 SDK 服务商认证。生产环境未在本次发布中自动部署。
