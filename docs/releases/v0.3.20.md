# 河豚运营中心 v0.3.20

修复手机端“最热影片”请求被拒绝的问题。本地只读 CMS 连接现在按真实 vod_hits 降序查询，再按页返回；热度相同时按影片 ID 降序排列。

- 分类、关键词和可见性筛选在热度排序前生效；手选影片继续保留指定顺序，最新和评分排序保持兼容。
- 热度查询跳过不含热度字段的搜索快照。HTTP 采集源或缺少热度字段的旧库会返回明确的能力错误。
- 共享应用设置新增默认关闭的 VPN 检测提醒开关，经 application/config 和 bootstrap 下发；Android 客户端可消费该策略，网页预览不执行系统 VPN 检测。本版不包含 Android 真机验收。
- 统一管理前端、manifest 与 Go 程序版本为 0.3.20。

发布提供 Linux amd64、Linux arm64、Windows amd64 压缩包和 SHA256SUMS.txt。已有安装可通过“系统管理 → 系统更新”更新；配置、数据与 CMS 内容保留。

本地验证：Go 测试355项通过、5项依赖外部数据库/Redis环境跳过；产物与前端回归92项通过；类型检查、生产构建和 go vet 通过。数据库及 Redis 测试由正式 CI 提供隔离服务后执行。主题中心保持本地开发联调，尚未在本版发布。
