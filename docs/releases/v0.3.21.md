# 河豚运营中心 v0.3.21

同服务器 CMS 安装现在会同时补齐管理适配器 Hetunops.php、播放权限与会员令牌适配器 Hetun.php，以及管理密钥配置。此前同机安装只包含管理适配器，导致目录可以正常读取，但缺少 Hetun.php 的站点在播放时返回 404。

连接配置提供两个适配器的独立下载。安装前检查全部目标文件；已有不同文件或非普通文件时停止，持久化失败只回滚本次新建文件，保留站点原文件。播放继续由 CMS 校验权限，不直接泄露目录中的播放地址。

回归覆盖完整安装、重复安装、原有播放适配器冲突、失败回滚、管理员下载权限和两份兼容源文件一致性；流水线检查两个 PHP 适配器语法。真实站点播放、会员与支付仍需分别验收。
