# 河豚运营中心 0.3.21 安装说明

解压后只有一个 hetun-operations 程序。网页、安装向导和接口都已内置，服务器无需安装 Node.js、Go 编译器，也不需要手写配置文件。

## 本版更新

- 页面编排中的已绑定轮播可选择五种样式，调整尺寸、边距、圆角和图片填充方式；修改自动保存到当前一级分类页面。
- 轮播外观按页面独立覆盖，支持恢复主题默认；前后端校验保持一致，旧配置继续继承主题。

- 应用设置统一维护四端共享的业务规则；导航、栏目和页面排版仍独立配置。
- 播放中心汇总播放源、解析调度、内核及弹幕设置，详情页和短剧页接入公共播放状态、试看及账号隔离的云历史。
- 公告在一个入口管理四端内容；新增 CMS 内容/会员管理与评论、弹幕审核。CMS 写入通过独立签名适配器，采集接口保持只读。
- 注册验证码、会员和头像规则、按内容源隔离的定时搜索索引接入公共配置。
- 保留一级分类独立页面、分类中间导航、轮播组自动命名及绑定，以及页面排序、名称和颜色编辑；补齐自动保存冲突及退出登录时待保存内容的处理。
- 正式流水线增加共享设置行为回归与 PHP 适配器语法检查，继续验证单程序归档、安装、CMS 模拟接口和更新契约。

本版交付运营中心、公共接口和现有 Vue 客户端组件。真实 CMS、宝塔生产环境、原生播放内核及设备仍需实际联调；模拟接口和 App 编译通过不代表原生设备验收完成。主题中心和打包器不在本次改动范围。

## 宝塔安装

1. 创建一个空文件夹，上传并解压 Linux 安装包。普通 x86 服务器选 linux-amd64，ARM64 服务器选 linux-arm64。
2. 宝塔创建一个独立空 MySQL 数据库，记下库名、用户名、密码，无需导入 SQL。安装并启动 Redis，记下监听地址、端口和密码（未设置可留空）。
3. 在宝塔「Go 项目 → 添加项目」选择解压的 hetun-operations 文件，项目名称填 hetun，项目端口填 8787，执行命令使用默认程序命令，无需参数；环境变量留空，运行用户 www，勾选开机自启。确保文件可执行、www 对程序所在目录有读写权限。
4. 启动后在项目日志查看「后台访问路径」和「后台地址示例」。打开 http://服务器IP:8787/日志中的随机路径。通过 IP 直连时需放行服务器防火墙和安全组的 8787 端口；使用域名则在宝塔项目中绑定域名及 HTTPS。
5. 网页自动填写网站来源地址，填写 MySQL、Redis 和自选管理员账号密码，两项连接测试通过后完成安装，再登录后台。

首次启动生成随机后台路径，例如 /8f2b6d。安装和登录使用同一地址，重启、升级后保持不变。安装完后，根路径和 /index.html 不开放后台，临时安装接口关闭；管理员登录验证仍然保留。客户端仍然使用固定 /api/ 接口，无需拼接后台随机路径。

运行后程序会在自身目录自动生成 config.json 和 data，这是保存数据库连接、随机入口、素材及日志所需的运行文件。安装包本身只有一个程序。不要把程序目录配置为可公开下载文件的静态网站。

默认监听 0.0.0.0:8787。端口占用时启动命令增加 --listen 0.0.0.0:8788，同时把宝塔项目端口改成 8788；首次安装后监听地址保存到配置。默认配置位置是程序旁，不依赖宝塔启动时的工作目录。随机入口忘记后查看启动日志即可。

连接成功代表数据库可连接；完成安装还需要建表和写入权限。保存配置失败时修复目录权限，使用同一管理员信息重试；已初始化的其他数据库不会被覆盖。

## 数据库连接失败时

安装页会区分认证失败（1045/1698）、数据库不存在（1049）、权限不足（1044/1142 等）、来源主机被拒绝、连接限额、地址解析失败、端口拒绝连接与超时。未知错误保留为通用提示，不向网页返回驱动原文、数据库密码或连接串。错误发生阶段与 MySQL 数字错误码通过安装接口返回，便于排查。

数据库名和用户名以宝塔完整名称为准，可以相同；数据库密码与宝塔登录密码是两套信息。三个密码框均可点击小眼睛临时显示，再次点击隐藏。连接测试不建表、不写入安装数据；完成安装才会检查建表和写入权限。只调整本次安装独立数据库，不应为修复单个库而影响其他数据库。

## CMS 与客户端

登录后台后再接入自己的苹果 CMS。分类和影片优先通过同机只读通道读取；会员令牌及播放权限需要 Hetun.php 兼容接口。运营程序已内嵌该适配器，可在「视频管理」或「用户管理」的连接配置中下载，手动放入 CMS 的 application/index/controller/Hetun.php；同机安装会同时补齐它和管理适配器。已有不同文件时停止安装，不覆盖站点修改。不同 CMS 修改版本仍需实际验收会员、付费影片及支付回调。

### CMS 管理适配器

内容管理、会员注册/升级及头像修改等写操作使用新管理适配器。在「内容管理」下载 Hetunops.php，放到 CMS 的 application/index/controller/Hetunops.php；在 application/extra/hetun_operations.php 配置相同的 64 位十六进制管理密钥，然后在运营中心填写管理接口地址和密钥并测试连接。同机安装功能仅适用于运营服务有对应 CMS 目录访问权限的场景。

密钥文件格式：

~~~php
<?php
return ['key' => '替换为自行生成的64位十六进制密钥'];
~~~

两个适配器源文件在 go-server/cms/，均已嵌入运营程序，安装归档仍只有一个可执行文件。Hetunops.php 负责签名管理请求，Hetun.php 负责 CMS 原有会员令牌与播放权限检查。同机安装先核对三个目标文件，再写入缺失文件；遇到不同文件或连接保存失败时，不覆盖原文件并回滚本次新建文件。文件安装完成和管理连接通过，不代表播放、会员及支付业务已经验收。请使用 HTTPS 并保持两端时钟同步，接入后验证实际站点权限。server/maccms-extension/Hetun.php 继续保留给旧版独立安装脚本，发布回归校验它与内嵌版本一致。

客户端固定接口：GET /api/bootstrap?platform=mobile&os=android&version=1.0.0；platform 支持 mobile/tablet/tv/web。运营协议 hetun-operations-v1，主题协议 hetun-runtime-v1。基础客户端必须实现协议，由本地打包器写入运营地址。运营端管理运营内容，不承担云打包或远程修改已打包主题。

## 升级

停止原程序，备份 MySQL、config.json 和完整 data 目录；只替换可执行文件后启动。升级保留配置、数据库和素材。0.3.0 旧配置首次升级会自动生成并保存随机后台路径，请查看新启动日志。

不要删除配置后对旧库重新安装。失败回退需恢复匹配的旧程序、数据库和数据目录。配置含数据库凭据，备份应限制访问权限。

## 开发与其他运行方式

高级配置、systemd 和 Nginx 示例保留在源码 deploy/go/ 目录，不放入用户安装包。Windows 版本用于本机运行；正式存储使用 MySQL，file 模式仍仅限本机测试。

业务备份命令为 ./hetun-operations --backup /绝对路径/backup.json，素材单独备份。--import-state 仅允许导入尚未初始化的空库。旧 Node 状态可先用 deploy/go/migrate-node-state.mjs 转换。

发布检查包括归档严格只有一个程序、实际进程启动、随机入口持久化、客户端接口及隔离 MySQL 安装测试。宝塔实站、生产 CMS、支付和客户端真机仍需实际环境验收。

管理员密码由你自行设置，只要求非空；不限制密码长度或字母数字组合。后台随机后缀为6位，旧版16位链接会自动跳转到短链接。安装完成后再次操作旧安装页会引导进入登录页面。

## Redis 与连接监控

首次安装同一步填写 MySQL 与 Redis。测试连接会验证 Redis 的 PING、临时键写入、读取及删除，再检查 MySQL；失败不会完成安装。程序自带 Redis 客户端，Redis 服务需在宝塔安装并启动。Redis 仅缓存成功的公共影片目录，默认 60 秒，故障时回退内容源。不会清空 Redis 或访问其他应用的键。

系统概览显示实际数据库、Redis 连接池及内容源 HTTP 请求统计，展开连接配置可查看版本、地址和连接上限；密码不会出现在监控接口。旧配置未设置 Redis 时显示未配置。

## 后台面板更新

安装含更新模块的版本后，在“系统管理 → 系统更新”点击“检查更新”，发现新版本后点击“安装更新”并确认。Linux amd64/arm64服务器自动下载对应包、校验和兼容检查，然后短暂重启。更新后重新登录；业务配置、数据库及素材保留。程序目录须允许运行用户创建和替换文件。GitHub无法访问或额度耗尽会如实显示失败。Windows预览仅检查版本。

维护者发布：更新package.json及锁文件对应版本后，推送匹配的 v版本号 标签。operations-release工作流通过构建与测试后，创建公开GitHub Release并上传单文件压缩包和SHA256SUMS.txt。只推源码不会变成可安装更新。正式安装包通过该工作流发布。

失败处理：下载、校验、配置预检失败保留原服务；exec系统调用失败尝试恢复.previous。新进程启动后的业务异常不自动回滚，可停服务后由维护者恢复.previous并按原启动命令启动；数据库迁移不由此自动回退。旧版本首次升级仍需手动替换一次程序才拥有面板更新入口。
